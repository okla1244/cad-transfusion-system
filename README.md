# 新竹縣消防局救災救護指揮中心 - 院前啟動輸血調度管制系統
Pre-hospital Blood Transfusion Dispatch Console

本系統為專為消防局救災救護指揮中心設計之院前輸血調度與管制系統，提供派遣員迅速進行血品調度、醫院端雙向確認、車輛與備血分隊指定及完整調度時間軌跡紀錄。

## 主要功能
- **調度總覽儀表板**：即時掌握今日案件統計、通報進行中狀態及即時時間。
- **標準化調度指引**：依 SOP 逐項引導指揮中心確認患者條件、聯絡責任醫院血庫與指定領血分隊。
- **通報文字一鍵產出**：自動產生標準派遣通報格式，便於複製貼入 CAD 或即時通訊軟體。
- **案件歷史調閱**：留存完整時間戳記軌跡與歷程。
